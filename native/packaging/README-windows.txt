segyread for Windows (beta)
===========================

segyread is a fast SEG-Y viewer, on its way to becoming the ultimate
SEG-Y QC tool. This is a beta: it works, but it isn't finished yet.

Start
-----
1. Unzip this folder anywhere (for example to your Desktop or C:\Tools).
2. Double-click segyviewer.exe.

Keep all files together: the .dll files and the subfolders are part of the
program. There is no installer and nothing is written to the registry.

Requirements
------------
- Windows 10 or 11, 64-bit
- A CPU with AVX2 (practically every PC from 2013 onward)

"Windows protected your PC"?
----------------------------
This beta isn't code-signed yet, so Windows SmartScreen may warn the first
time. Click "More info", then "Run anyway".

Privacy
-------
segyread works offline and makes no network connections. Its only own
file is .segyread_settings in your user folder (delete it to reset).
