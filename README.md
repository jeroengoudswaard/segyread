# segyread

Fast SEG-Y reader with dedicated QC options.

This repository currently tracks the native C++/Qt6 rewrite in
[`native/`](native/README.md) — see that file for the full design writeup,
build instructions (Windows, Ubuntu/Qt6, Rocky/RHEL 8/Qt5), feature list,
and test/benchmark status.

An earlier Flutter-based prototype also exists locally but isn't part of
this repository yet.
